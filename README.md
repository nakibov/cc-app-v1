# cc app 1.1

Калибровка скорости роста лучевой концентрации по ИК от среднего ионного тока QMS.

Двойной щелчок по [cc.html](cc.html) открывает приложение без установки и без сервера. Тот же файл можно переслать коллеге.

Либо из исходников:

```bash
npm install
npm run dev
```

Загрузите файл масс-спектрометра (Pressure vs Time, `.txt`) и пронумерованные ИК-спектры (`.csv`). Либо откройте пример CO₂. На обзоре отметьте прямоугольники двумя кликами — по порядку спектров. Для каждой пары слева сигнал QMS, справа ИК.

- Базовая линия QMS усредняется окном 15 с. Площадь — интервал на плато. «Автопрямоугольник» ставит это окно внутри выбранного участка так, чтобы слева и справа от границ было не меньше 10 с стабильного тока. Зафиксированные пары не трогает.
- Коррекция домножает площадь ИК на `S_good / S_full`. Автокоррекция берёт `S_full` между границами базы.
- Сила полосы понимает и латинскую `e`, и русскую `е` (`1.6e-17` и `1,6е-17`). Рядом — поле «температура, источник».
- Скорость `v = A · ln(10) · k / (Δt · S)`. Точка (0, 0) и полином без свободного члена, порядок 1–5. Точки в таблице можно добавить и убрать.
- «Сохранить кк» отдаёт архив `молекула ГГГГ-ММ-ДД.zip`: точки, полином, PNG и интерактивный график с той же таблицей.
