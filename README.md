# cc app v1

Калибровка скорости роста лучевой концентрации по ИК от среднего ионного тока QMS.

Загрузите файл масс-спектрометра (Pressure vs Time, `.txt`) и пронумерованные ИК-спектры (`.csv`, волновые числа в см⁻¹, десятичная запятая). Либо откройте пример CO₂. На обзоре отметьте прямоугольники двумя кликами — по порядку спектров. Для каждой пары слева сигнал QMS, справа ИК.

- Базовая линия QMS усредняется окном 15 с. Площадь — интервал SpanSelector. Средний ток — `S_good / Δt`.
- Коррекция домножает площадь ИК на `S_good / S_full`. Автокоррекция берёт `S_full` между границами базы.
- ИК интегрируется между двумя границами ν. Сплайн и магнит (±2 см⁻¹) включаются галочкой коррекции.
- Скорость `v = A · ln(10) · k / (Δt · S)`. Точка (0, 0) и полином без свободного члена, порядок 1–5.
- «Сохранить» отдаёт архив: точки, полином, PNG, интерактивный график и все параметры обработки.

```bash
npm install
npm run dev
```

Приложение работает в браузере, без серверной базы.
